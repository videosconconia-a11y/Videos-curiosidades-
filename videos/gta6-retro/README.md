## Prompt
> 9:16 Short, ~38 s, English, upbeat female narrator. "What if GTA 6 came out on retro consoles?" Each console gets a
> drawn generic CRT TV (or a generic grey handheld), a big name + year label, and official GTA VI images converted to that
> machine's limits: Atari 2600 (40×30 blocks, 8-colour palette, "Is that Lucia, or a rectangle?"), Game Boy (160×144,
> 4 greens, Bayer dither), NES (72×54, 10 colours, error-diffusion), PlayStation 1 (160×120, colour banding, ordered dither,
> wobbling rows), Nintendo 64 (bilinear smear + fog), PS5 (clean) → red "30 FPS" stamp joke. TV-static channel changes,
> synthwave grid floor, outro grid of all 6 screens numbered 1–6 ("Which one? Comment below"). Chiptune score that changes
> with each console (pulse arps, square + triangle + noise, pad + breakbeat, cinematic boom for PS5). No console logos.

Years: Atari 2600 1977, Game Boy 1989, PlayStation 1994 (JP), PS5 2020 — release years.
